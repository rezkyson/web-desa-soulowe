# Produk — Desa Soulowe

Sumber kebenaran: `prd.md` dan `TASK.md`. Website informasi Desa Soulowe, Kecamatan Sigi Kota, Kabupaten Sigi. Pengunjung mencari profil, data agregat, pemerintahan, keuangan, berita, dokumentasi, dan kontak kantor. Satu operator mengelola konten dinamis.

## Konteks dan keputusan pengguna

- Bahasa Indonesia; nyaman di ponsel dan koneksi terbatas.
- Publik tanpa akun. Admin satu akun, tanpa registrasi atau manajemen pengguna.
- Tidak ada layanan surat/pengaduan, data individual, marketplace, batas wilayah, etnis, atau program per bidang.
- Modern, clean, resmi, hangat; anti-template generik. Logo `logo.png` digunakan apa adanya.
- Arah hijau hutan, putih hangat, tipografi rapi, foto lanskap dominan disetujui pengguna melalui pertanyaan terstruktur pada 21 November 2026.
- Admin harus jelas, efisien, dan tidak mengandalkan estetika promosi.
- Animasi singkat, tidak berlebihan, mendukung reduced motion.
- Data 2026, keuangan mengikuti dokumen tanpa kalkulasi turunan. Konten tetap dikunci dari admin.

## Tahap saat ini

Fase 1: frontend dengan mock dalam memori. Login, upload, serta simpan/hapus hanya simulasi, bukan keamanan atau persistensi server. Backend, integrasi, testing menyeluruh, dan deploy menunggu gerbang persetujuan masing-masing.

## Keterbatasan skill

Launcher Impeccable berhasil memuat konteks, namun pembacaan file referensi pendukung ditolak lingkungan, termasuk setelah pengguna memberikan izin. Implementasi mengikuti instruksi skill yang sudah termuat dan brief eksplisit; tidak mengklaim referensi yang ditolak telah dibaca.
